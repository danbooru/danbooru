# Security Policy

## Reporting a Vulnerability

If you find a security issue that is immediately exploitable and should be kept private until it's fixed, report it by
opening a private security advisory on GitHub:

https://github.com/danbooru/danbooru/security/advisories/new

Otherwise, for lower-risk or more general issues that don't need to be kept private, you can open a normal issue at:

https://github.com/danbooru/danbooru/issues/new

## Guidelines

* **One issue per report.** Report each bug separately. Don't bundle multiple unrelated issues into a single report. Related bugs can be bundled.
* **Include a proof of concept or steps to reproduce.** Show how to trigger the bug and what the impact is. Include URLs where possible.
* **Use testbooru for testing.** Don't use the main site for testing or demonstrating bugs; you can use https://testbooru.donmai.us instead.
* **If you used an LLM to help write your report, make sure a person can understand it.** Keep it short and to the
  point, and verify the steps to reproduce it actually work before submitting.
